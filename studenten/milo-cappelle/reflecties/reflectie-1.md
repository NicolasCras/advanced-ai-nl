# Reflectie 1

## Wat kan mijn tool nu?
De tool werkt momenteel goed bij aanvragen waar de standaard termen zoals 'slopen' of 'graven' in staan. Bij andere aanvragen gaat het ook al goed, maar is er soms nog wat twijfel.

## Wat kan hij niet?
De tool kan niet altijd logisch nadenken zoals wij mensen dat kunnen. Bijvoorbeeld bij een aanvraag voor een uitbreiding van 4 meter van een woning denkt de tool dat dit niet voor Deprez is. Maar bij een uitbreiding moeten er ook vaak buizen gelegd worden en nieuwe fundaties geschept worden. Ook telt de tool zaken mee die al gedaan zijn, waarvoor de aanvraag gewoon later wordt ingediend.

## Welk cijfer bewijst dat?
Met prompt v2 op Haiku 4.5 gaf de tool 4 keer een ander antwoord bij dezelfde input (F6), vooral tussen "ja" en "onzeker" (n = 14, 2 runs). Dat is de twijfel. In totaal was "interessant" 23 op 28 juist.
