# Build — weekanalyse sporter

Taalmodel dat de trainingsnotities van één week en het doel van de sporter leest en een oordeel (belasting, herstel) plus advies voor volgende week geeft, in vaste velden.

- `taak.md` — de keuze in vijf regels
- `regels.md` — mijn regeltabel (bron van de juiste antwoorden)
- `prompt.md` — huidige prompt (oudere versies: `prompt-v1.md`, `prompt-v2.md`)
- `test-set.md` — inputs, juiste antwoorden, runs
- `log.md` — logboek
