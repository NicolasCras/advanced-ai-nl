# Mijn scenario

1. **De plek:** mijn eigen leven als student IBM, jaar 3, aan Arteveldehogeschool.
2. **De beslissing:** Moet ik, als student IBM, mijn tool die opdrachten en deadlines uit een Canvas-vakpagina haalt, elke werkdag gebruiken om mijn deadlines te checken, in plaats van de vakpagina's met de hand na te kijken?
3. **De lezer:** ik zelf, want het is mijn eigen leven.
4. **Waarom het ertoe doet:** Als ik fout kies, kost het me ofwel ± 9 uur en ± €153 per jaar (als ik de tool niet gebruik, terwijl hij helpt), ofwel een gemiste deadline en 0 punten voor die opdracht (als ik de tool blind vertrouw). Mijn testset geeft nu 1 op 5 juist (n = 5, 1 run), dus nakijken blijft nodig.
5. **Wat ik nog moet uitzoeken:**
   - De echte prijs van Haiku 5.5, want hij staat niet in de tabel van de README en mijn kostberekening is daarvan afgeleid.
   - De tokens van mijn meting, zodat mijn kost per run (nu $0,0039) onderbouwd is.
   - Hoe lang het nakijken met de hand en met de tool echt duurt. Mijn 5 min en 2 min zijn geschat en nog niet gemeten.
   - Hoe vaak ik de tool echt gebruik. De 20 runs per maand is een schatting.
   - Of mijn succespercentage (nu 1 op 5, n = 5) hoog genoeg wordt om de tool te vertrouwen.
