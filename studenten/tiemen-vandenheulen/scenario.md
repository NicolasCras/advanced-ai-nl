# Mijn scenario

1. **De plek:** Mijn eigen toekomstig muziekfestival.
2. **De beslissing:** Moet mijn toekomstig muziekfestival mijn review-sorteerder gebruiken om bezoekersreviews te categoriseren?
3. **De lezer:** Ikzelf als organisator.
4. **Waarom het ertoe doet:** Zonder de tool kan het sorteren van reviews meer tijd kosten, tot hogere kosten leiden en meer handmatige fouten veroorzaken.
5. **Wat ik nog moet uitzoeken:** De exacte AI-kost per run en op schaal.
