# Kosten per run

Datum: 14 oktober 2026

## Meting

Ik deed één run met mijn prompt en testinput T01 in Codex. De context steeg van 16,3K naar 17,0K tokens. De run gebruikte dus ongeveer 700 tokens.

Codex toont de input- en outputtokens niet apart. Omdat mijn prompt veel langer is dan het korte JSON-antwoord, gebruik ik als transparante schatting 650 inputtokens en 50 outputtokens. Voor de prijs gebruik ik GPT-6.1 Sol uit de cursusprijstabel: $2 per miljoen inputtokens en $10 per miljoen outputtokens. Ik reken om met $1 = €0,90.

| Model | Context / beginwaarde | Totaal / eindwaarde | Jouw deel | Kost per run | Per maand, 20 reviews | 10×, 200 reviews | 1.000×, 20.000 reviews |
|---|---:|---:|---:|---:|---:|---:|---:|
| GPT-6.1 Sol | 16,3K | 17,0K | 700 tokens (650 input, 50 output geschat) | €0,00162 | €0,0324 | €0,324 | €32,40 |

## Berekening

- Input: 650 × $2 / 1.000.000 = $0,00130
- Output: 50 × $10 / 1.000.000 = $0,00050
- Totaal: $0,00180 × 0,90 = €0,00162 per run

## Volume

Ik schat 20 reviews per maand op basis van een verwacht bezoekersaantal van 750 en mijn eigen ervaring. Dat is ongeveer 2,7% van de bezoekers. Bij tien keer dit volume zijn dat 200 reviews per maand; bij duizend keer dit volume 20.000 reviews per maand.
